## Graphical setup and routine
Prototype is a native desktop Tk window, not browser disk access. Existing trusted Windows Python 3.12 with Tcl/Tk and pythonw file association, and existing Gpg4win in Program Files are prerequisites. Python availability on the owner PC is not established; no installs approved or performed. After SOL/PM exact source review, extract these three companion source files to an owner-controlled local folder outside backup storage; use Explorer to double-click gui.pyw (or Open with installed Python windowed launcher). No CMD/PowerShell for routine use. No auto installer, elevation, service, scheduled job or stored settings. Start, select a local USB/fixed drive, see free capacity, click Create synthetic backup, type the displayed one-time fixture code and use GPG's separate graphical Pinentry passphrase. Cancel requests stop; close waits for outcome. Copies are stored under DAWNEY_BACKUPS/STAGING/SYNTHETIC_FIXTURES/fixture-UTC-UUID, distinct from real staging database backups; production disabled. Only fixture data embedded in code, not SQL/database data, no selectable input files. Do not use fixture output for clinic recovery. 16 MiB reserve is fixture-only, not database sizing. OS/filesystem writable status proven by exclusive ciphertext file creation, no pre-existing file replaced/deleted. Drive availability/identity and free space checked before operations, reparse paths rejected at creation, not an adversarial local filesystem boundary. Failure leaves incomplete artifacts; receipt.json status verified_synthetic_fixture is last success marker, absence means NOT VERIFIED even if directory renamed. No secrets, paths, real user identifiers or provider records in receipt; local unsigned receipt not tamper-proof. GPG encrypt/decrypt using binary pipes, AES256, no plaintext file, hash of complete decrypted fixture and format match, ciphertext readback and SHA256. Bounded fixture bytes in memory, not real PG archive or managed restore. GUI Pinentry requires interactive Windows testing. No broad PAT, token, password, provider connectivity, remote command or network listener.
